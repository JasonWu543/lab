Method

工作方式：测试先行的闯关制

每个单元的「完成」不由感觉定义，由测试定义。接口先在 SPEC 里冻结，测试先于实现存在（此时全红），然后手写实现直到全绿：

SPEC 冻结接口→ 测试全红→ 手写实现→ 测试全绿→ Review→ Postmortem
Claude —— 出题人 + 助教
  • 写 SPEC、带 TODO 的骨架代码
  • 写测试关卡与 benchmark 脚手架
  • 藏参考答案于 reference/（卡 30 分钟才许看）
  • 提交后 review、注 bug 出演练题
我 —— 实现者
  • 手写全部核心算法代码
  • 跑 pytest 闯关直到全绿
  • 对照参考答案说出自己版本差在哪
  • 写 postmortem：错误、返工、学到什么
铁律：出题人绝不替学生写核心实现——即使学生说「效率优先，你来写」。答案只进 reference/，答题文件必须留白。

Schedule

十二周路线

每周 15–25 小时；同一时间最多两条活跃线。出口标志是硬门槛：不达标砍下周副线来补，不顺延总工期。

周主线出口标志
W1M1: BPE → 最小 Autograd（副线 M7 演练 PR 闭环）round-trip + gradcheck 通过，第一个完整 PR
W2–3M1: Qwen-like Transformer过拟合 + cached/non-cached logits 对齐
W4M1: Trainer + 云端训 50–100M中断恢复演示 + checkpoint 产出
W5–6M4: mini-vLLM（副线 M7 四 Agent 并发开发）continuous batching 跑通 + vLLM 对比报告
W7M4: 投机解码（副线 M2 fused kernels）采样分布一致性检验通过
W8–9M3: MoE / DeepSeek 机制消融MoE vs Dense 等算力结论
W10–11M5: SFT → DPO → GRPO（副线 M6 数据工程）reward 上升且无 hacking
W12缓冲 + 总结全部 postmortem 汇总成总结报告

算力策略：本地 Mac 写代码跑单测，云端租单卡 4090/5090 只跑正式实验，每个实验事先标注 S（≤2 GPU·h）/ M（≤12）/ L（≤48）级别。

Readings

读什么

每个模块配约五篇文献，动手前只精读打 ★ 的一两篇，其余遇到问题再查——不用读论文推迟写代码。当前阶段（M1）的必读：

★Neural Machine Translation of Rare Words with Subword UnitsSennrich 2016 · paperBPE 用于 NLP 的原论文，Phase 1.0 的算法基础。
★karpathy/minbperepo200 行 Python 从零实现 BPE，工程细节最清晰的教学实现。
★Automatic Differentiation in ML: a SurveyBaydin, JMLR 2018 · paper自动微分最权威综述，reverse mode 的数学本质。
★karpathy/microgradrepo150 行标量级 autograd，理解「backward 为什么保存前向激活」最直观。
★Attention Is All You NeedVaswani 2017 · paperPhase 1.2 的起点。
