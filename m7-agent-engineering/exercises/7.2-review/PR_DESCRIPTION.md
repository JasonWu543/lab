## Summary

This PR adds a self-contained Python package for the token sampling and KV
cache management stack we use in our inference server. Previously this logic
was scattered across three modules with no unit tests. This package:

- Centralises temperature sampling, top-k, top-p, and repetition penalty
  in `sampling.py` with full type hints and docstrings
- Provides a clean KV cache API in `kv_utils.py` with sliding-window
  trimming, memory estimation, and concatenation helpers
- Adds `metrics.py` for offline perplexity evaluation and throughput tracking
- Includes `bench.py` to compare eager vs. `torch.compile` throughput

All functions follow the (batch, heads, seq, dim) tensor convention used
throughout the codebase.
